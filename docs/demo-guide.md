# Phase 3 demo guide

> **Synthetic demo disclaimer:** The workflows, vendors, documents, products, connectors, metrics, users, and outputs described here are synthetic unless a user uploads a local file. CatalogForge AI does not claim real customer data, production integrations, extraction accuracy, or compliance certification.

## Journey 1 — supplier catalog to mock Shopify
1. Sign in as `catalog.ops@catalogforge.demo`.
2. Open Intake Inbox and select a supplier batch.
3. Inspect document evidence and correct a blocking field.
4. Approve the product and inspect channel readiness.
5. Create a change set.
6. Switch to `publishing@catalogforge.demo` and run a mock publish/dry run.
7. Open lineage and audit history.

## Journey 2 — duplicate governance
Use `reviewer@catalogforge.demo`, open Duplicate Resolution, compare evidence and placeholder images, choose a canonical record, complete second review if prompted, then inspect decision history.

## Journey 3 — vendor quality
Use `vendors@catalogforge.demo`, identify a low-quality vendor, inspect recurring validation issues, create an intake-link simulation, and open template metadata.

## Journey 4 — reconciliation
Use `publishing@catalogforge.demo`, inspect an out-of-sync synthetic record, run reconciliation, and view the durable job/audit output.

## Journey 5 — launch readiness
Use `admin@catalogforge.demo` or `compliance@catalogforge.demo`, open Launch Readiness, review release-gate evidence, inspect the permission matrix, and walk the guided golden-demo sequence before opening Publish.
